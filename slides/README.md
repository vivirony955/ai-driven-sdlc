# Lecture slides

One PowerPoint deck per chapter, bridge, and appendix — **33 decks** in total,
designed to be lectured from directly or adapted for your own course.

These are companion materials to the textbook and are licensed
[CC BY 4.0](../LICENSE): use and adapt them in teaching with attribution.

## Naming

| Pattern | Example | Maps to |
|---|---|---|
| `chN.pptx` | `ch7.pptx` | Chapter *N* |
| `bridge<Name>.pptx` | `bridgeEthics.pptx` | the named Bridge chapter |
| `appendix<X>.pptx` | `appendixA.pptx` | Appendix *X* |

| File | Topic |
|---|---|
| `ch1.pptx` … `ch24.pptx` | Chapters 1–24 |
| `bridgeRE.pptx` | Bridge — Requirements Engineering |
| `bridgeArch.pptx` | Bridge — Architecture Patterns |
| `bridgeData.pptx` | Bridge — Data Engineering |
| `bridgePlanning.pptx` | Bridge — Project Planning & Estimation |
| `bridgeEthics.pptx` | Bridge — Ethics & Responsible AI |
| `bridgeCareer.pptx` | Bridge — Career & Industry Context |
| `appendixA/B/C.pptx` | Appendices A/B/C (Atlas Learn case studies) |

## Using the slides

- **Present as-is** — open in PowerPoint, Keynote, or Google Slides (import).
- **A combined PDF** of all decks is attached to each [release](../releases/) and
  can be rebuilt locally with `scripts/build-artifacts.sh` (uses LibreOffice).
- **Adapt freely** — reorder, trim, or re-theme for your class. If you publish a
  derivative, keep the CC BY attribution (see the [README](../README.md#how-to-attribute)).

## Contributing

Slide fixes (a wrong label, a clearer diagram) are welcome. Because `.pptx` is
