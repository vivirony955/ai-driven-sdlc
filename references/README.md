# References

This directory holds the project's **bibliography and further-reading list**, plus
guidance on **how to cite this book**.

- [`bibliography.md`](bibliography.md) — curated references and further reading,
  organized by theme.
- [`CITING.md`](CITING.md) — ready-to-paste citations for this book (BibTeX, APA,
  MLA, Chicago) and the machine-readable [`CITATION.cff`](../CITATION.cff).

## Why this exists

The textbook is a self-contained theoretical framework and (in its v1.0 form) does
not carry an academic-style reference section. For classroom and research use,
this directory provides:

1. **A place to cite the book itself** consistently — see [`CITING.md`](CITING.md).
2. **A curated reading list** that situates the framework in the broader
   literature on software engineering, LLM agents, and responsible AI.

> The reading list is a **community-maintained** resource and a documented gap in
> v1.0 (it starts small). Additions are welcome — see the contribution note in
> [`bibliography.md`](bibliography.md).

## Citation style

For contributions to this repository's own references, use a lightweight,
consistent style:

> Author(s). *Title*. Publisher/venue, year. URL (accessed YYYY-MM-DD).

For coursework built on the book, follow your institution's required style; the
[`CITING.md`](CITING.md) file provides the book's details in the four most common
formats.
