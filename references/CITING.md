# How to cite this book

The canonical, machine-readable citation metadata lives in
[`../CITATION.cff`](../CITATION.cff). On GitHub, use the **“Cite this repository”**
button (top-right of the repo page) to get an always-current BibTeX/APA snippet.

Below are ready-to-paste forms. Replace `vivirony955`, the access date, and the version
with the edition you used; the DOI line is included for when a release is archived
to Zenodo (see [`../releases/README.md`](../releases/README.md)).

> Throughout: **Title** = *An AI-Driven Software Development System: A Theoretical
> Framework for the Modern Software Engineering Lifecycle*; **Author** = The
> AI-Driven SDLC Authors; **Year** = 2026; **Version** = 1.0.

## BibTeX

```bibtex
@book{aidrivensdlc2026,
  title     = {An AI-Driven Software Development System: A Theoretical Framework
               for the Modern Software Engineering Lifecycle},
  author    = {{Vivek Negi}},
  year      = {2026},
  edition   = {1.0},
  publisher = {Self-published (open access)},
  url       = {https://github.com/vivirony955/ai-driven-sdlc},
  note      = {Open educational resource, CC BY 4.0}
}
```
