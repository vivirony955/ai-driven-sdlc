# Brand & presentation assets

Shared visual assets for the project — kept separate from in-book
[`../figures/`](../figures/) (which are content) because these are *packaging*:
the cover, logo, and the images GitHub and social platforms display.

## Wanted (placeholders for now)

| File | Purpose | Spec |
|---|---|---|
| `cover.png` | Book cover (PDF/EPUB, website hero) | ~1600×2400, < 2 MB |
| `logo.svg` | Project mark (README, website, favicon source) | square, transparent |
| `social-preview.png` | GitHub social card / Open Graph image | **1280×640** (GitHub requirement), < 1 MB |
| `favicon.png` | Website tab icon | 512×512 |

These are **not yet created** (documented gap — see [ROADMAP.md](../ROADMAP.md)).
Until they exist:

- The website falls back to a text title and a default theme color.
- GitHub will auto-generate a social card; replace it under
  **Settings → General → Social preview** once `social-preview.png` exists (see
  [Phase 6 publishing notes](../releases/PUBLISHING_CHECKLIST.md)).
