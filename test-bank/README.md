# Instructor test bank

[`AI_Driven_SDLC_TestBank.docx`](AI_Driven_SDLC_TestBank.docx) — a complete
question bank covering every chapter, bridge, and appendix.

## What's in it

For each section the bank provides three question types:

- **Multiple choice** — recall and basic application; each includes the correct
  answer and a brief rationale.
- **Short answer** — application and analysis; each includes a model answer.
- **Essay** — synthesis and evaluation; each includes a grading rubric/guidance.

Every question is **tagged with the learning objective it tests** (e.g. `[LO 7.2]`)
so you can assemble assessments that map directly to your syllabus outcomes.
Appendix questions use an `App-A` / `App-B` / `App-C` tag scheme to avoid
collision with the bridge tags.

> ⚠️ **This edition includes answer keys.** It is published in full in this public
> repository by project decision. If you need an exam-secure subset, generate one
> for your own use and do not redistribute it — search engines will index anything
> committed here.

## Suggested use

- **Quizzes:** pull 4–8 multiple-choice items per chapter.
- **Exams:** mix multiple-choice (breadth) with one or two short-answer/essay
  items (depth), keeping the LO tags balanced across the outcomes you taught.
- **Self-check:** learners can use the multiple-choice sections with the rationale
  hidden.

The [educator guide](../website/docs/adopt/educators.md) shows how the bank, the
slides, and the chapter exercises line up.
