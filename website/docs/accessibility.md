# Accessibility

We want this book to be usable by everyone — including readers who use screen
readers, keyboard navigation, magnification, or high-contrast modes.

## Status at a glance

- ✅ **Reflowable EPUB & HTML** for magnification and small screens
- ✅ **Clean heading structure** drives navigation and the table of contents
- ❌ **Figure alt-text** is still being added — this is our top accessibility gap
- 🟡 Color contrast, table markup, and reading order are being verified

## Help us

Adding **figure alt-text** is the single most valuable accessibility
contribution — and an easy first pull request.
