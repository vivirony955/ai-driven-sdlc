# Self-learner guide

No course, no deadline — just you and the book. Here's how to get the most from it.

## A 6-week self-study plan (~3–4 hours/week)

| Week | Read | Goal |
|---|---|---|
| 1 | Preface, Ch 0–2 | Why this matters; the core mental models |
| 2 | Ch 3–4 (+ RE & Architecture bridges) | How the work federates and how systems are layered |
| 3 | Ch 5–9 (+ Data bridge) | The operating disciplines: context, tokens, governance, prompts, the tracker |
| 4 | Ch 10–12 | The agents and the anti-patterns that sink them |
| 5 | Ch 13–16 | Quality: testing, security, performance, observability |
| 6 | Ch 17–23 (+ Planning & Ethics bridges) + an appendix | Operating in the real world; principles; one full case study |

Then keep **Ch 24 (Glossary)** and the **bridges** as references you return to.

## If you're short on time

Read the **skeptic's path**: Preface → Ch 1 (why) → Ch 22 (limits, honest
disclosure) → Ch 23 (final principles). If it convinces you, go back and read the
middle.

## How to make it stick

- After each chapter, check yourself against its **learning objectives** (`LO N.*`).
- Use the [**test bank**](../../../test-bank/) as flashcards — read a multiple-choice
  question, answer it, then read the rationale.
- Apply each operating discipline to **a system you actually know** (at work, a side
  project, or an open-source project you use). The framework is meant to be
  portable — that's the whole point of the many-domains examples.
- Read the **Atlas Learn** callouts and appendices to see the ideas in one
  continuous story.

## Make it yours

- Grab the [**EPUB or PDF**](https://github.com/vivirony955/ai-driven-sdlc/releases/latest)
  to read and annotate offline.
- Keep notes against the chapter learning objectives — they double as a study guide.

## Give back

Self-learners catch the things that confuse newcomers. If something tripped you up,
[open an issue](https://github.com/vivirony955/ai-driven-sdlc/issues/new/choose) or
suggest clearer wording — see [CONTRIBUTING.md](../../../CONTRIBUTING.md). Adding
**figure alt-text** is the quickest way to contribute.
