# Contribute

This is an open educational resource — errata, clearer explanations, exercises,
figure alt-text, references, and translations are all welcome.

The full guide lives in the repository:

[:material-file-document: CONTRIBUTING.md](https://github.com/vivirony955/ai-driven-sdlc/blob/main/CONTRIBUTING.md){ .md-button .md-button--primary }
[:material-account-group: Code of Conduct](https://github.com/vivirony955/ai-driven-sdlc/blob/main/CODE_OF_CONDUCT.md){ .md-button }

## The two-minute version

1. **Found a typo or error?** Open an
   [errata issue](https://github.com/vivirony955/ai-driven-sdlc/issues/new/choose) and
   quote the chapter and sentence.
2. **Want to improve the text?** The manuscript is a Word file, so prose changes go
   through issues (or a Track-Changes `.docx`) rather than raw PRs — see
   [CONTRIBUTING.md](https://github.com/vivirony955/ai-driven-sdlc/blob/main/CONTRIBUTING.md#editing-the-manuscript).
3. **First time?** Adding
   [figure alt-text](https://github.com/vivirony955/ai-driven-sdlc/blob/main/figures/FIGURES.md)
   is the easiest way in — and improves accessibility for everyone.

Code, exercises, examples, references, and website changes go in as normal pull
requests.

## Good first issues

- ♿ **Figure alt-text** — pick a `_TODO_` row in the figure registry.
- 📚 **A reference** for the further-reading list.
- 📝 **An erratum** — the highest-signal way to improve the prose.

Thank you! 🙏
